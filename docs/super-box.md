# 超级输入框

按 **Alt+Space** 打开，只用键盘就能做事：

- 找到并执行软件的功能、[动作](actions.md)、设置页、收藏的文件夹；
- 跳到一个路径；
- 新建文件或文件夹。

Esc、点框外或再按一次 Alt+Space 关闭。

GNOME 默认把 Alt+Space 给了窗口菜单，KDE 上常给了 KRunner，系统会先拿走这个键。
这时到 **设置 → 快捷键** 里给“超级输入框”换一个键。

## 模式

框左边显示当前模式，**Tab** 切到下一种，**Shift+Tab** 切到上一种，点模式按钮也行。框里的字切换时留着。

| 模式 | 做什么 | 前缀 |
|---|---|---|
| 搜索 | 找功能、动作、设置页、收藏 | 不用前缀 |
| 路径 | 跳到一个文件夹或文件 | `g:` |
| 新建 | 在当前文件夹新建文件或文件夹 | `n:` |

- 前缀是切换模式的快捷写法：在开头打 `g:` 就切到路径模式，前缀本身不留在框里。全角冒号 `：` 也认。
- 在搜索模式里以 `/` 或 `~` 开头，也会切到路径模式。
- 打开框时的模式在 **设置 → 常规 → 超级输入框默认模式** 里选，默认是搜索。

## 搜索

边打边列，最多 10 条。上下键选，回车或单击执行。每条后面写着它是功能、动作、设置还是收藏，以及它的快捷键。

- 功能：执行它等于按了它的快捷键，比如“新建文件夹”“显示隐藏文件”“打开终端”。
- 动作：只列对当前选中项适用的动作（没选东西时是当前文件夹），包括 Dolphin 服务菜单。
- 设置：打开设置窗口到那一页。
- 收藏：打开侧栏里收藏的文件夹。

怎么算匹配，越靠前排得越前：

1. 整个名字完全对上，或者拼音首字母对上整个名字（`kjj` → 快捷键）；
2. 名字开头，比如 `新建`；
3. 名字里某个词的开头；
4. 拼音首字母开头，比如 `xjwjj` → 新建文件夹；
5. 名字里任意位置；
6. 功能的英文名，比如中文界面里打 `new folder`。

同一档里按功能、动作、设置、收藏的顺序，再按名字长短。

不分大小写，全角字母按半角算。

## 路径

- `~` 是主目录，相对路径从当前文件夹算起。
- 第一条是“跳到 …”，下面列出补全出来的子文件夹。上下键选，回车直接打开。
- 是文件夹就打开它；是文件就打开它所在的文件夹并选中它；不存在时框里说明，框不关。

## 新建

- 写名字：`笔记.md` 新建空文件，`素材/` 新建文件夹。
- 名字不能用、或者当前文件夹里已经有这个名字时，框里说明，不会新建。
- 建好后选中它。按 Ctrl+Z 能撤回。
- 回收站里、压缩包里、搜索结果里不能新建。

## 历史

- 框是空的时候，列出这个模式下最近执行过的输入，最新的在上。
- 选中一条按回车，只是把它填进框里，再按一次回车才执行。
- 最多记 100 条，重启后还在。
