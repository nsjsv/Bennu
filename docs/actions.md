# 自定义动作

一个动作就是一个 `.toml` 文件，放在 `$XDG_CONFIG_HOME/bennu/actions/`（默认 `~/.config/bennu/actions/`）。
动作会出现在适用项目的右键菜单里，也可以在 **设置 → 快捷键** 最下面的“动作”组里给它绑键。
文件一保存就生效，不用重启。**设置 → 动作** 列出所有动作，写错的文件也在那里，带着原因和行号。

一个动作由几步组成，上一步的结果交给下一步：

```toml
name = "提取音频"
types = ["video/*"]

[[steps]]
convert = "m4a"

[[steps]]
move_to = "{dir}/音频"

[notify]
title = "音频提取好了"
body = "{count} 个文件 → {dir}"
```

右键一个或几个视频，选“提取音频”：先转成 m4a 放在视频旁边，再把转出来的文件移进同一个文件夹下的“音频”文件夹（没有就新建）。
做完弹出自己写的通知。按一次 Ctrl+Z，整个动作一起撤回。

## 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 菜单、设置页、F1 里显示的名字 |
| `types` | 否 | 对哪些项显示，见下文；不写就是所有文件和文件夹 |
| `steps` | 是 | 一步或几步，按顺序执行 |
| `notify` | 否 | 结束时的通知，见下文 |

动作的身份是文件名（不含 `.toml`）。快捷键按文件名记，改了文件名要重新绑键。

## 对哪些项显示（`types`）

写 MIME 类型，规则和 Dolphin 的服务菜单一样：

- 具体类型：`image/png`。它的子类也算，比如 `application/gzip` 也包括 `.tar.gz`。
- 一大类：`video/*`、`image/*`、`audio/*`。
- 文件夹：`inode/directory`。
- 所有文件（不含文件夹）：`application/octet-stream`。

选中多项时，每一项都要匹配。在空白处右键时，动作作用在当前文件夹上，所以适用于 `inode/directory` 的动作也会出现在空白处的菜单里。
回收站里和压缩包里面不显示动作。

类型只按文件名判断，打开菜单时不读文件内容。

## 步骤

每一步写一个键：

| 步骤 | 写法 | 做什么 | 交给下一步 |
|---|---|---|---|
| 转换 | `convert = "m4a"` | 用这种格式在转换对话框里的出厂设置转换，结果放在原文件旁边 | 转出来的文件 |
| 压缩 | `compress = "zip"`（或 `7z`、`tar.gz`） | 打成一个压缩包，放在第一项所在的文件夹 | 压缩包 |
| 解压 | `extract = "here"` / `extract = "folder"` | 和右键菜单的“智能解压到当前文件夹”/“解压到归档文件夹”一样 | 解出来的那一项 |
| 复制到 | `copy_to = "~/备份/{date}"` | 复制进这个文件夹，没有就先建 | 复制出来的项 |
| 移动到 | `move_to = "{dir}/音频"` | 移进这个文件夹，没有就先建；已经在里面的项不动 | 移动后的项 |
| 移到回收站 | `trash = "current"` / `trash = "selected"` | 把当前这批，或者动作开始时选中的项移到回收站。只能是最后一步 | 没有 |
| 执行命令 | `run = "…"` | 执行外部命令，见下文 | 原样交下去 |
| 复制路径 | `copy_paths = true` | 把当前这批的路径复制到剪贴板 | 原样交下去 |

`convert` 能写的格式：

- 图片：`jpg png webp avif jxl tiff bmp gif ico`
- 视频：`mp4 mp4-h265 mkv mkv-av1 webm webm-av1 mov avi gif`
- 音频：`mp3 m4a opus ogg flac wav`

视频也能转成音频格式，就是提取声音；视频转 `gif` 是动图。这一批里转不了的项不参加，在最后的通知里报出来。

步骤也可以写成一行：

```toml
steps = [{ convert = "m4a" }, { move_to = "{dir}/音频" }]
```

### 文件夹里的变量

复制到、移动到的文件夹按每一项各算一次：

| 变量 | 值 |
|---|---|
| `{dir}` | 这一项所在的文件夹 |
| `{name}` | 名字，比如 `会议.mp4` |
| `{stem}` | 去掉扩展名的名字，比如 `会议` |
| `{ext}` | 扩展名，不带点，比如 `mp4` |
| `{date}` | 动作开始那天，比如 `2026-11-19` |

文件夹必须以 `/`、`~/` 或 `{dir}` 开头。要写大括号本身，写 `{{` 和 `}}`。

### 执行命令

```toml
run = "ffmpeg -i {file} -vn {dir}/{stem}.wav"
```

- 用了 `{file}`（完整路径）、`{name}`、`{stem}`、`{ext}`、`{dir}` 中的任何一个，就每一项执行一次。
- 用了 `{files}`，所有项一起作为参数执行一次，比如 `run = "sha256sum {files}"`。`{files}` 要单独作为一个参数。两种不能混用。
- 都没用就执行一次，比如 `run = "git pull --ff-only"`。
- 在当前标签页的文件夹里执行。

命令按 shell 的引号规则切成参数，但**不经过 shell**：文件名里有空格、引号、`;`、`$()` 也只是参数内容，不会被当成命令。
所以管道、重定向、`&&` 这些不能直接写；要用的话，自己写 `sh -c '…'`。

命令退出码不是 0 就算失败，失败原因带着它最后几行输出。命令放在任务队列里，可以暂停和取消，取消时它启动的子进程也一起结束。
程序退出后，没跑完的命令不会自动重跑。

## 运行、失败和撤销

- 每一步都放进任务队列，面板里显示“动作名 · 步骤 (2/3)”。
- 一步失败或被取消，后面的步骤就不跑了；已经做完的保留，不会删掉生成的文件。
- 一步里个别文件失败（比如 10 个视频有 1 个转不了），用成功的继续往下走，失败的在通知里报出来。
- 从不覆盖：目标里已经有同名项时，自动编号（“名字 2”）。
- 删除只用回收站，没有永久删除这一步。
- 按一次 Ctrl+Z 撤回整个动作，倒着撤回每一步：转换、压缩、解压生成的文件移到回收站，复制出来的移到回收站，移动的移回原处，自动建的空文件夹收掉。
  Ctrl+Shift+Z 整个重做。执行命令做了什么 Bennu 不知道，撤销时跳过这一步。
- 动作结束时结果在当前文件夹里的话，会选中这些结果。

## 通知（`notify`）

三选一：

- **不写**：和其他操作一样，只在窗口不在前台时弹“动作名 完成”。
- **自己写**：窗口在前台也弹。

  ```toml
  [notify]
  title = "音频提取好了"
  body = "{count} 个文件 → {dir}"
  ```

  可用变量：`{action}` 动作名、`{count}` 结果数、`{name}` 第一个结果的名字、`{dir}` 第一个结果所在的文件夹、`{failed}` 没处理成的项数。`body` 可以不写。
- **不通知**：`notify = "none"`，什么都不弹，只在任务面板里看。

失败时（前两种）总是弹“动作名 失败：原因”。动作里各步自己的“完成”通知不弹。

## 安全

动作能执行命令，所以只用你自己的文件：

- 文件和文件夹必须属于你自己（或 root），而且别的用户不能改（不能是其他人可写，`chmod o-w`）。不满足的文件不加载，设置页会说明原因。
- 写错的文件整份不用，不会只执行一半。

## 例子

解压，然后把压缩包移到回收站：

```toml
name = "解压并删除压缩包"
types = ["application/zip", "application/x-7z-compressed", "application/x-compressed-tar"]

[[steps]]
extract = "here"

[[steps]]
trash = "selected"
```

更新 git 仓库：在文件夹上右键对那个文件夹，在空白处右键对当前文件夹（`{file}` 就是那个文件夹）：

```toml
name = "git pull"
types = ["inode/directory"]
notify = "none"

[[steps]]
run = "git -C {file} pull --ff-only"
```

压缩后复制路径：

```toml
name = "打包并复制路径"

[[steps]]
compress = "zip"

[[steps]]
copy_paths = true
```
