# 超级输入框

按 **Alt+Space** 打开，只用键盘就能做事：

- 找到并执行软件的功能、[动作](actions.md)、设置页、收藏的文件夹；
- 在索引里找文件；
- 跳到一个路径；
- 新建文件或文件夹；
- 在当前文件夹执行一条命令。

Esc、点框外或再按一次 Alt+Space 关闭。

GNOME 默认把 Alt+Space 给了窗口菜单，KDE 上常给了 KRunner，系统会先拿走这个键。
这时到 **设置 → 快捷键** 里给“超级输入框”换一个键。

## 模式

打开时输入框里什么都没有，直接打字就是默认模式（**设置 → 常规 → 超级输入框默认模式**，默认是搜索）。
要用别的模式就在开头打它的标签（下表的前缀），输入框最前面会出现写着模式名字的胶囊；框空着时按退格删掉胶囊，回到默认模式。

- 框空着时按 **Tab**，下面列出能打的标签，再按 Tab 一个个换。
- **Shift+Tab** 也能直接切到下一种模式。框里的字切换时留着。

| 模式 | 做什么 | 前缀 |
|---|---|---|
| 搜索 | 找功能、动作、设置页、收藏，最后也列索引里名字对上的文件 | 不用前缀 |
| 文件 | 在索引里找文件，可以写筛选 | `f:` |
| 路径 | 跳到一个文件夹或文件 | `g:` |
| 新建 | 在当前文件夹新建文件或文件夹 | `n:` |
| 命令 | 用你的 shell 在当前文件夹执行一条命令 | `s:` |

- 在开头打 `g:` 就切到路径模式，前缀变成前面的胶囊。全角冒号 `：` 也认。
- 在搜索模式里以 `/` 或 `~` 开头，也会切到路径模式。

## 搜索

边打边列，最多 10 条。上下键选，回车或单击执行。每条后面写着它是功能、动作、设置还是收藏，以及它的快捷键。

- 功能：执行它等于按了它的快捷键，比如“新建文件夹”“显示隐藏文件”“打开终端”。
- 动作：只列对当前选中项适用的动作（没选东西时是当前文件夹），包括 Dolphin 服务菜单。
- 设置：打开设置窗口到那一页。
- 收藏：打开侧栏里收藏的文件夹。

怎么算匹配，越靠前排得越前：

1. 整个名字完全对上，或者拼音首字母对上整个名字（`kjj` → 快捷键）；
2. 名字开头，比如 `新建`；
3. 名字里某个词的开头；
4. 拼音首字母开头，比如 `xjwjj` → 新建文件夹；
5. 名字里任意位置；
6. 功能的英文名，比如中文界面里打 `new folder`。

同一档里按功能、动作、设置、收藏的顺序，再按名字长短。

不分大小写，全角字母按半角算。

搜索服务在跑时，最后还会列最多 5 个名字对上的文件（停顿一下才查）。

## 文件

在整个索引里找（和搜索页的“全部”范围一样），边打边列前 10 条，停顿一下才查。
索引里只有文件，搜索服务不收文件夹，所以这里找到的都是文件；找文件夹用路径模式。

- 回车：进入所在文件夹并选中它。多栏视图里按 **设置 → 常规 → 多栏视图里打开找到的文件** 来：
  - **从第一栏往下展开**（默认）：第一栏不动，一栏一栏展开到所在文件夹；文件不在第一栏下面时，从两者共同的上级开始；
  - **所在文件夹作第一栏**；
  - **直接打开文件**：用默认程序打开。
- **Ctrl+Enter**：在当前标签页打开搜索页，词和筛选都带过去。
- 搜索服务没在运行时，框里会说明，可以到 **设置 → 搜索** 里启动。

筛选可以写在任何位置，键和值都是中英文两种写法都认：

| 筛选 | 写法 | 能写的值 |
|---|---|---|
| 类型 | `类型:图片` / `type:images`，几种用逗号分开：`类型:图片,视频` | 图片 视频 音频 文档 文本 表格 PDF 压缩包 文件夹 文件 链接 |
| 时间 | `时间:7天` / `time:7d` | 今天 昨天 7天 30天 一年（today yesterday 7d 30d 1y），按修改时间 |
| 大小 | `大小:>10m` / `size:<1g` / `size:10m-1g` | 单位和搜索页的自定义大小一样 |

例子：`f: 季度报告 类型:文档 时间:30天`。写错的筛选，框里会说明能写什么。

## 命令

用你的 shell 在当前文件夹执行：和终端面板是同一个 shell（**设置 → 常规 → Shell**，没选就是登录 shell）。
管道、通配、`&&` 都能用。

- 选中的项作为参数传进去：bash、zsh、sh 里是 `"$@"`（`$1`、`$2`……），fish 里是 `$argv`。
  名字只是参数，不会被当成命令，名字里有 `$(…)` 也一样。比如 `s: du -sh "$@"`。
- 回车：命令在后台的终端里跑（和终端面板一样是真的终端，输出带颜色、会分页、能问密码）。
  框里显示“正在执行”、最后几行输出，和“转到终端”“停止”两个按钮。
  跑完显示退出码和输出的最后几百行（就是终端里显示的样子，长的可以滚动）。
- 程序一打开全屏界面（vim、less、top、btop 这些），就整个移进底部的终端面板接着用，不重跑；框自己关掉。
  在终端面板里退出程序，那个终端标签就关了。
- 要输密码、要回答问题时（比如 `sudo`），点 **转到终端**，到终端面板里输。
- **停止**：先让命令自己结束，2 秒后还没结束就强行结束（连它开的子进程一起）。
- 每条命令最后一次的结果都记下来（最近 20 条命令，每条最多 16 KB，重启后还在），框关着时跑完的也记。
  转到终端面板的命令不记，它的输出在终端里。
  命令模式里框是空的时候列出历史命令，上下键停在哪一条，下面就显示它上次的输出和时间。
- 中途关掉框，命令照样跑完。命令不进任务面板，不能暂停。
- **Ctrl+Enter**：改成打开底部的终端面板，在那里的 shell 里执行。这时选中项不会传进去。
- 只有在命令模式里按回车才会执行。从历史里选出来的命令只是填进框里，要再按一次回车。
- 命令做了什么 Bennu 不知道，所以不能用 Ctrl+Z 撤回。

## 管道

像 shell 的管道：`|` 前面挑文件，后面接一步或几步，上一步的结果交给下一步。在搜索模式（不打标签）和文件模式（`f:`）里写；命令模式里的 `|` 还是 shell 自己的管道。

```
*.mp4 | 提取音频
f: 类型:图片 时间:今天 | 压缩 zip | 移动到 ~/备份
| 复制路径
```

`|` 前面挑哪些：

- 什么都不写：选中的项。
- `*.mp4`、`报告-*.pdf`：当前文件夹里名字匹配的（通配同 shell，`*` 不匹配 `.` 开头的名字）。只看当前文件夹；要找别处的用 `f:`。
- 文件模式里写的是索引查询，写法和筛选同[文件](#文件)。

`|` 后面每一段是一步：

- 一个[动作](actions.md)的名字，比如 `提取音频`：它的各步原样接进来。
- 或者一步的写法，和动作文件里的键一样，中英都认：

| 写法 | 做什么 |
|---|---|
| `转换 m4a` / `convert m4a` | 转换格式 |
| `压缩 zip` / `compress zip`（或 `7z`、`tar.gz`） | 打成一个压缩包 |
| `解压` / `extract`（`解压 folder` 解压到归档文件夹） | 解压 |
| `复制到 ~/备份` / `copy_to …` | 复制进这个文件夹 |
| `移动到 {dir}/音频` / `move_to …` | 移进这个文件夹 |
| `回收站` / `trash`（`回收站 selected`） | 移到回收站，只能是最后一步 |
| `执行 …` / `run …` | 执行命令（不经过 shell） |
| `复制路径` / `copy_paths` | 复制路径 |

- Dolphin 服务菜单也能写名字，但只能是最后一段：前面的步骤做完，把结果交给它。
- 文件夹里的变量（`{dir}`、`{date}` 这些）、命令的写法和动作文件一样，见[动作](actions.md#步骤)。

写好后框里一行预览，比如“12 项 → 转换 m4a → 移动到 {dir}/音频”，按回车才执行。执行和动作一样：进任务队列、能取消，按一次 Ctrl+Z 整串撤回。

- 写错了、一项都没挑到时，框里说明，不执行。
- 一次最多 1000 项，再多就加筛选缩小范围。
- 按 **Ctrl+S** 存成动作：打开 **设置 → 动作** 的编辑页，步骤已经填好，起个名字、选对哪些文件显示，点保存。以服务菜单结尾的不能存。
- `|` 后面也能按 Tab 补全动作名和步骤的写法，复制到、移动到后面补文件夹。

## 补全

路径模式和命令模式里，补全和 fish 一样：

- 边打边在后面用淡色显示一个建议：先找这个模式的历史里接得上的那条，没有再找文件名（命令模式的第一个词找命令名）。按 **→**（或 End、Ctrl+F）接受。
- **Tab** 补最后那个词：只有一个就补全（文件夹后面带 `/`，命令模式里文件和命令后面带空格）；有好几个就补到它们共同的开头；补不动时在下面列出来，再按 Tab 一个个换进框里，打字就收起。
- 大小写对得上的优先，没有再不管大小写。`.` 开头的只在你也打了 `.` 时才列。
- 命令模式里名字带空格这些，补出来时前面加反斜杠。

## 路径

- `~` 是主目录，相对路径从当前文件夹算起。
- 第一条是“跳到 …”，下面列出补全出来的子文件夹。上下键选，回车直接打开。
- 是文件夹就打开它；是文件就打开它所在的文件夹并选中它；不存在时框里说明，框不关。

## 新建

- 写名字：`笔记.md` 新建空文件，`素材/` 新建文件夹。
- 名字不能用、或者当前文件夹里已经有这个名字时，框里说明，不会新建。
- 建好后选中它。按 Ctrl+Z 能撤回。
- 回收站里、压缩包里、搜索结果里不能新建。

## 历史

- 框是空的、没有胶囊时，列出最近 5 条（各种模式混在一起，默认模式以外的每条前面带它的胶囊）；有胶囊时列这个模式最近 3 条。最新的在上。
- 一条历史都没有时，下面显示这个模式怎么用。
- 选中一条按回车，只是把它填进框里，再按一次回车才执行。
- 最多记 100 条，重启后还在。
